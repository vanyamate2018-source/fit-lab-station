# FIT-LAB Station

Модульная система видеоприёма, управления и диагностики.

## Основные роли

- **Мастер-пульт** — главный интерфейс и координатор системы на Mac или отдельном одноплатном компьютере.
- **Модуль видеоприёма** — headless-узел без GUI: WFB-ng, RX1/RX2, радиостатистика и передача видеопотока.
- **Модуль управления** — отдельный будущий headless-узел: PAN/TILT, CRSF, INA219, IMU и датчики положения.
- **SDR-модуль** — отдельный будущий узел: спектр, сканирование, аналоговое видео и запись IQ.

## Принципы

1. Модули независимы: сбой одного не должен останавливать остальные.
2. Мастер-пульт автоматически обнаруживает, регистрирует и контролирует совместимые модули.
3. Обычный интерфейс показывает понятные пользовательские статусы; технические детали находятся в разделе «Сервис».
4. Камерный OSD не изменяется; диагностическая панель FIT-LAB выводится отдельно.
5. Большие рабочие данные хранятся вне Git: записи, IQ, телеметрия, журналы, резервные копии и секреты.
6. Разработка начинается на macOS, затем аппаратные службы переносятся и проверяются на Linux/SBC.

## Статус

Архитектурный каркас проекта. Реальная совместимость оборудования отмечается только после проверки на конкретном железе.

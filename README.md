# FIT-LAB Station

Модульная система видеоприёма, управления и диагностики.

## Архитектура

- **Мастер-пульт** — основной интерфейс и управление системой.
- **Модуль видеоприёма** — headless-узел WFB-ng с RX1/RX2 и передачей видеопотока.
- **Модуль управления** — отдельный будущий узел для сервоприводов, CRSF и датчиков.
- **SDR-модуль** — отдельный будущий узел для спектра, сканирования и аналогового видео.

Главный принцип: модули независимы. Сбой или перезапуск одного модуля не должен останавливать остальные.

## Разработка на Mac

Базовая установка:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -e '.[dev]'

Графический Мастер-пульт:

    python -m pip install -e '.[dev,ui]'
    python -m master.gui

Текстовая проверка Мастера:

    python -m master.app

## Данные

Рабочие данные не хранятся в Git. Путь задаётся локальной конфигурацией FIT-LAB.

Текущая Mac-конфигурация:

    /Volumes/FIT-LAB/data

Подробный архитектурный план: `docs/architecture/system-plan.md`.

## Проверки

Core-тесты запускаются автоматически в GitHub Actions на Python 3.12 и 3.14.

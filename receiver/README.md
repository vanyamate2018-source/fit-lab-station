# Модуль видеоприёма

Headless-служба без графического интерфейса.

Назначение:
- RX1 / RX2;
- WFB-ng;
- статистика радиоканала;
- передача чистого видеопотока на Мастер-пульт;
- контроль собственного состояния;
- опциональная локальная запись.

Не содержит CRSF, сервоприводы и управление аппаратом.

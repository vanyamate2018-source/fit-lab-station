# Сенсорные экраны

Проверенное распознавание 26.09.2026: QDtech MPI7009, USB 0712:0009.
Linux: hid-multitouch + libinput, ID_INPUT_TOUCHSCREEN=1, direct-input, multitouch slots.
Драйвер уже штатный; отдельный перехватчик и права root не нужны.

shared/linux_touch.py определяет прямые сенсоры по возможностям ввода, не по имени,
номеру event или номеру USB-порта. Тачпад/мышь не объявляются сенсорным экраном.
Опрос присутствия раз в 2 секунды; отключённый сенсор исчезает из статуса.
master/ui/touch.py сохраняет список в logs/touch-status.json.
Ввод и мультитач обрабатывает Linux/Qt. Приложение не читает чужие нажатия.

Новые экраны: проверить hid-multitouch/libinput, прямые координаты X/Y,
ориентацию и соответствие монитору. При нескольких мониторах калибровка индивидуальна;
общую матрицу для всех устройств не устанавливать. Физические жесты на Linux пока
не подтверждены пользователем; обнаружение и системное включение проверены.

Обновление интерфейса: «Система → Экран» показывает обнаруженный сенсор и размер экрана. Вертикальная прокрутка настроек использует QScroller TouchGesture. Горизонтальный свайп по нижней панели переключает разделы; область видео и ползунки не используются для навигационных свайпов. Простое касание кнопки выполняется один раз, мультитач отменяет одиночный навигационный жест.

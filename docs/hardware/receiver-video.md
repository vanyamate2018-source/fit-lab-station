# Видеовывод приёмника

На проверенном Linux-приёмнике экран 1024×600, 60 Гц. Камера передаёт H.265 1280×720 около 30 кадров/с.

Аппаратное декодирование: GStreamer mppvideodec. Вывод: xvimagesink в собственное окно приложения. Сохраняются пропорции кадра; размеры области передаются плееру при изменении окна и при полном экране. Счётчик FPS — фактически выведенные кадры из статистики видеоплеера.

Пересылка RTP и учёт пакетов выполняются отдельным потоком RtpRelay. Интерфейс получает статистику, а не обрабатывает каждый пакет. Opus направляется только в аудиоплеер. Запись и трансляция получают исходные пакеты без добавления очереди кадров.

Проверка 26.09.2026: прежний вывод через копирование RGB показывал 7–16 FPS; копирование поверхности занимало до 20–60 мс. Прямой XVideo-вывод показал около 29–32 FPS, с отдельными просадками под нагрузкой. Эти цифры не измеряют задержку камера–экран.

GLX в установленной системе использует программный llvmpipe. EGL/Mali прошёл пробу создания контекста, но встроенный glimagesink дал чёрное окно; этот путь отключён. XVideo выбран по фактической проверке, а не по названию GPU.

При ошибке аппаратного вывода предусмотрено одно переключение на совместимый RGB-вывод; радио не требуется перезапускать. Полноэкранное окно сохраняется до завершения приложения, чтобы плеер не обращался к уже удалённому X11-окну.

Служба радио и графическое приложение разделены. Обычный запуск приложения не включает просмотр или запись. Автозапуск открывает интерфейс; просмотр запускается кнопкой.

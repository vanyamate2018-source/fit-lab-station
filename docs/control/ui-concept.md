# FIT-LAB Master - концепция Video + Control

## Основной экран

Центр остаётся за живым видео. Управление не должно заслонять FPV.

Нижняя зона видео:
- два визуальных стика;
- ARM/DISARM;
- режим полёта;
- каналы;
- latency / packet loss.

Левая колонка:
- RX1/RX2;
- запись;
- трансляция;
- состояние видеотракта.

Правая колонка:
- FIT-LAB TX;
- FIT-LAB RX;
- RP2040;
- Power Board;
- voltage/current;
- LQ/RSSI/SNR;
- краткая телеметрия.

Верхние разделы:
- Видео;
- Управление;
- Телеметрия;
- Карта;
- Настройки;
- Система.

## Темы

Две целевые визуальные темы:
- Cyan / холодная технологическая;
- Amber / тёмный графит + янтарные акценты.

Amber является полноценной темой, а не просто заменой одного цвета.

## Интерактивный макет

Файл:
`docs/control/demo/FIT-LAB-Master-Control-Demo.html`.

Макет не выполняет реальные RF/GPIO-команды. Он симулирует:
- движение стиков;
- 8 каналов;
- задержку;
- RSSI/LQ/SNR;
- Power Board;
- ARM/DISARM;
- FreeRTOS state;
- аварийную остановку;
- переключение Cyan/Amber.

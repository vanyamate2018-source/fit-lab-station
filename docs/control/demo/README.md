# FIT-LAB Control Demo

Откройте `FIT-LAB-Master-Control-Demo.html` в браузере.

Это безопасный UI/UX-макет:
- не подключается к USB;
- не открывает UART;
- не отправляет RF;
- не меняет настройки TX/RX;
- не выполняет GPIO-команды.

В макете работают:
- анимированный тестовый прогон;
- стики и каналы;
- ARM/DISARM только как визуальная симуляция;
- FreeRTOS state;
- Power Board ON/OFF только как визуальная симуляция;
- телеметрия;
- переключение Cyan / Amber.

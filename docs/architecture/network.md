# Сетевой слой FIT-LAB

## Текущий этап

Первый сетевой прототип использует JSON-сообщение `module.hello` поверх UDP.
Это позволяет проверить:

- сериализацию протокола;
- идентификацию типа модуля;
- передачу возможностей;
- обработку входящего объявления Мастер-пультом;
- регистрацию модуля в общем реестре.

## Ограничения прототипа

Текущий UDP-прототип пока не является механизмом доверия или аутентификации.
Он не должен использоваться для выдачи прав управления.

## Следующие этапы

1. Периодический heartbeat.
2. Аутентификация зарегистрированных модулей.
3. Capability/version negotiation.
4. Управляющий канал поверх надёжного транспорта.
5. Отдельный поток видео и телеметрии.
6. Автоматическое обнаружение в LAN без привязки к localhost.

Права управления, CRSF и опасные действия будут добавляться только после отдельного слоя аутентификации и failsafe.

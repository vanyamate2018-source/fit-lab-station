# Сетевой слой FIT-LAB

## Текущий этап

Сетевой прототип использует JSON-пакеты поверх UDP.

Поддерживаются два сообщения:

- `module.hello` — первичное объявление модуля и его возможностей;
- `module.heartbeat` — подтверждение, что зарегистрированный модуль остаётся в сети.

Мастер-пульт ведёт локальный реестр модулей. Если heartbeat пропадает дольше заданного тайм-аута, модуль переходит в состояние «нет связи». Возобновление heartbeat возвращает его в состояние «готов» и фиксируется в журнале.

Повторное `module.hello` от уже известного модуля не создаёт повторное событие «Модуль готов».

## Важно

Этот слой пока решает только обнаружение и контроль присутствия. UDP-пакеты ещё **не аутентифицированы** и не дают права управления. CRSF, сервоприводы, изменение радиопараметров и другие критичные действия через этот канал запрещены до добавления отдельного механизма доверия.

## Следующие этапы

1. Аутентификация зарегистрированных модулей.
2. Capability/version negotiation.
3. Надёжный управляющий канал.
4. Разделение управляющего трафика, телеметрии и видеопотока.
5. Автоматическое обнаружение в реальной LAN.
6. Защищённое назначение единственного владельца управления.

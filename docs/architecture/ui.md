# UI Мастер-пульта

## Цель

Интерфейс должен одинаково понятно работать на Mac, большом мониторе и небольшом HDMI/сенсорном дисплее.

## Визуальный принцип

- тёмный технический интерфейс без декоративного шума;
- крупные кнопки, пригодные для сенсорного экрана;
- отдельные стили обычных, основных, сервисных и опасных действий;
- состояние видно по тексту и цвету, а не только по цвету;
- при уменьшении окна боковая панель автоматически сворачивается;
- никакой фиктивной телеметрии.

## Компоновка

- сверху: переключатель Broadcast | SDR и краткий статус станции;
- слева: навигация Broadcast;
- в центре: рабочая область;
- перед видеокадром: источник и безопасные навигационные действия;
- под видеокадром: RX1, RX2, FEC, потери, запись и состояние видеолинка;
- отдельные быстрые переходы к Записи, Трансляции и Диагностике.

## Кнопки

Действующие навигационные кнопки активны сразу.

Команды, способные изменить состояние удалённого оборудования, остаются заблокированными до реализации доверенной привязки и защищённого управляющего канала:

- перезапуск службы;
- перезагрузка модуля;
- выключение модуля;
- физическое управление;
- изменение радио.

## Правила видео

- камерный OSD не перекрывается интерфейсом FIT-LAB;
- станционные показатели находятся вне изображения;
- при отсутствии данных показывается «—» или «Нет данных»;
- полноэкранный режим включается только после появления реального видеопотока.

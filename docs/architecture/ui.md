# UI Мастер-пульта

## Цель

Интерфейс должен одинаково понятно работать на Mac, большом мониторе и небольшом HDMI/сенсорном дисплее.

## Компоновка

- верхний переключатель режимов: Broadcast | SDR;
- слева — навигация Broadcast;
- центр — рабочая область;
- снизу видеокадра — отдельная строка радиостатистики и записи;
- состояние хранилища и общий статус видны без открытия сервисных страниц.

## Правила

- никаких вымышленных RSSI/FEC/потерь;
- при отсутствии данных показывается «—» или «Нет данных»;
- камерный OSD не перекрывается интерфейсом FIT-LAB;
- опасные действия недоступны, пока модуль не подключён и не доверен;
- технические UUID и сырой журнал скрыты от обычного экрана;
- боковая панель сворачивается для небольших дисплеев.

## Разделы Broadcast

1. Видеоприём
2. Модули
3. Камеры
4. Радиосвязь
5. Запись
6. Трансляция
7. Наведение
8. Диагностика
9. Настройки
10. Сервис

## Текущий этап

Первый GUI-каркас содержит реальное состояние хранилища, состояние основных модулей и пустой видеокадр без фиктивной телеметрии.

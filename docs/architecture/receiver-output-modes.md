# FIT-LAB WFB — режимы приёмника

Зафиксировано пользователем 26.09.2026.

Роль устройства остаётся «Приёмник». Его локальное приложение имеет полный интерфейс.
Независимые переключатели: «Просмотр здесь», «Передача мастеру», «Веб-трансляция».
Варианты: только локальный просмотр; только мастер; оба одновременно; все выходы выключены.
Отключение просмотра не должно останавливать радиоприём и другие выходы.
Остановка радиоприёма — отдельная явная кнопка. Запись запускается только вручную.
Один процесс владеет радиомодулями; окна не запускают конкурирующие USB-приёмники.
Настройки камеры/частоты требуют единого владельца управления с подтверждением смены.

Точка доступа: SSID «FIT-LAB WFB». Отдельный встроенный Wi-Fi/совместимый адаптер,
не RX1/RX2. Проверить AP-mode, драйвер, диапазон и конфликт подсетей до включения.
Пароль защищённого Wi-Fi задаётся пользователем; не публикуется в инструкции/отчёте.
Веб-плеер доступен без интернета, показывает состояние потока и поддерживаемые функции записи.
QR-код/ссылка в приложении. Автооткрытие страницы на телефоне не гарантируется без captive portal.

Статус: требования согласованы; переключение выходов и точка доступа на Linux ещё не проверены.

Дополнение: раздача сети подчинена трансляции на мастере и приёмнике.
Если трансляция выключена, принадлежащая FIT-LAB точка доступа выключена.
При остановке, ошибке запуска трансляции и выходе приложения точка доступа освобождается.
Обычное клиентское подключение Wi-Fi и чужие точки доступа не отключаются.
Показывать отдельно подтверждённые состояния плеера и точки доступа; ошибка выключения не скрывается.
Автовосстановление потока не должно бесконечно перезапускать Wi-Fi и отключать зрителей.

# Архитектура FIT-LAB

## Роли

### Мастер-пульт
Главный пользовательский интерфейс и координатор.

### Модуль видеоприёма
Специализированный headless-приёмник видео.

### Модуль управления
Отдельный исполнительный модуль для CRSF, сервоприводов и датчиков.

### SDR-модуль
Независимый модуль аналогового приёма и анализа.

## Отказоустойчивость

- потеря Master не должна останавливать Receiver;
- сбой Control не должен влиять на видеоприём;
- сбой SDR не должен влиять на Broadcast;
- потеря клиента трансляции не должна влиять на запись и основное видео.

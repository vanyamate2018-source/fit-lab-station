# FIT-LAB Navigation

FIT-LAB Navigation — слой отображения положения, курса и направления движения дрона в Мастер-пульте.

## Цель v1

Показывать оператору на карте:
- текущее положение дрона;
- положение станции/точки старта, если оно известно;
- направление носа;
- фактическое направление движения по земле;
- высоту;
- скорость;
- расстояние до Home/контрольной точки;
- траекторию;
- качество навигационных данных.

Навигация не должна зависеть от видеопотока. Если видео потеряно, карта и телеметрия продолжают работать, пока есть канал управления/телеметрии.

## Источники данных

Приоритетный путь:

```text
Flight Controller
→ CRSF/MAVLink telemetry
→ FIT-LAB RX
→ ExpressLRS
→ FIT-LAB TX
→ RP2040
→ Orange Pi
→ LAN
→ FIT-LAB Station
```

Для карты нужны как минимум:
- latitude;
- longitude;
- relative/absolute altitude;
- ground speed;
- course over ground;
- heading/yaw, если доступен;
- GPS fix;
- satellites;
- horizontal accuracy/HDOP, если доступно;
- Home position.

Важно различать:
- **Heading** — куда направлен корпус;
- **Course over ground** — куда аппарат реально движется.

При боковом ветре эти направления могут отличаться и должны отображаться отдельно.

## Карта

В UI:
- иконка дрона поворачивается по heading;
- линия движения строится по course over ground;
- Home/контрольная точка имеет отдельный маркер;
- предыдущий трек хранится ограниченно;
- при устаревших координатах маркер становится «Нет свежих данных», а не продолжает двигаться по прогнозу;
- карта не должна скрывать главный видеопоток.

Предусмотреть:
- режим «Видео»;
- режим «Карта»;
- режим «Видео + карта»;
- быстрое центрирование на дроне;
- центрирование на Home;
- масштаб по дистанции.

## Навигационный статус

Показывать:
- GPS: нет / 2D / 3D;
- спутники;
- возраст позиции;
- heading source;
- distance to Home;
- bearing to Home;
- altitude;
- ground speed;
- navigation warning.

Нулевое значение не подставляется вместо отсутствующего.

## Безопасность

Карта — отображение, а не единственный источник решения для failsafe.

Возврат при потере связи должен выполняться в первую очередь средствами flight controller, который продолжает стабилизацию независимо от Mac/Orange Pi.

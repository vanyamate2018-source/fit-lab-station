# FIT-LAB firmware

Раздел будущих прошивок подсистемы FIT-LAB Control.

Планируемые компоненты:

- `bridge-rp2040` — FIT-LAB Control Bridge;
- `tx-expresslrs` — FIT-LAB TX build/fork/patch-set на базе ExpressLRS;
- `rx-expresslrs` — FIT-LAB RX build/fork/patch-set на базе ExpressLRS.

Текущая документация: [docs/control](../docs/control/README.md).

До появления проверенного исходного кода этот каталог не должен содержать фиктивные бинарники или заявлять поддержку конкретного target.
